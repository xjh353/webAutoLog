# Global：项目级目标与边界

## 总目标

交付一个可在本机重复运行的 Web 日志异常与审计程序。使用者从原始日志出发，获得带事件证据的候选告警，并记录人工处置；评价者能用固定合成数据独立复算规则结果。需求、输入/规则契约分别见 `README.md`、[项目设计](project.md)、[规则卡](rules.md)。

## 成功判据

1. JSONL 和常见 Common/Combined 日志可导入；无效行与重复 ID 有明确原因，事件时间统一为 UTC。
2. 请求规则与 60 秒窗口规则产生可回查的 `eventIds`；报告保存数据集、运行和规则版本；处置记录包含状态变化、操作人及理由。
3. `npm test` 全部通过，`npm run eval` 输出会话级 TP/FP/FN/TN 和分母；实验比较使用预设质量门槛，并把失败和未知成本如实记录。
4. 从干净仓库可按[启动与演示指南](启动与演示指南.md)运行；报告与真实日志不纳入 Git。

## 范围与责任

当前交付范围是单机、离线、教学规模的候选异常审计。网页默认 P2-R1；P2-R2 是获批压测清单的实验候选。系统不自动封禁、不验证操作人真实身份、不提供生产级并发、权限或实时采集。标签仅用于评价；是否确认异常、业务阈值及真实数据使用由人负责。
