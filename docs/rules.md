# P2 规则卡

所有规则基于有效、去重后的事件。缺少会话 ID 时按日志中的 `remote_addr`、`client_ip` 或 `ip` 分组；只有未经代理规则确认的 `http_x_forwarded_for` 时，不使用它做窗口分组。既无会话又无可信来源地址的事件仍可触发单条请求规则，但不参与窗口聚合。IP 只是网络线索，不代表个人身份。`source_label` 不参与判断。

| 规则 | 分组 | 时间与窗口 | 阈值或条件 | 输出证据 | 版本 |
| --- | --- | --- | --- | --- | --- |
| 疑似 SQL 注入、XSS、路径穿越、敏感路径、扫描器特征 | 单条事件 | 事件时间 | 请求路径或 User-Agent 命中固定模式 | 命中事件 ID、规则名、级别、建议 | P2-R1、P2-R2 |
| 登录失败激增 | 服务＋会话；无会话则来源 IP | UTC 事件时间，`(t-60 秒, t]` | 登录路径且状态为 401/403/429，达到 5 次 | 窗口内相关事件 ID 和次数 | P2-R1、P2-R2 |
| 4xx 错误激增 | 同上 | 同上 | 8 次 | 同上 | P2-R1、P2-R2 |
| 5xx 错误激增 | 同上 | 同上 | 5 次 | 同上 | P2-R1、P2-R2 |
| 高频请求 | 同上 | 同上 | 30 次 | 同上 | P2-R1、P2-R2 |

同组同规则每分钟最多产生一条候选告警。P2-R2 唯一变化：若服务和会话 ID 的组合出现在调用方提供的外部已批准压测清单中，高频请求告警写入 `suppressed`，保留理由和事件 ID；其他规则照常执行。默认网页调用 P2-R1。阈值是教学值，未按真实业务流量校准。
